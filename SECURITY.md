# Безопасность

Нашли уязвимость в сервере, сайте, клиенте или боте ORICHILL?
Не публикуйте её в issues. Напишите на **support@orichill.net** с темой «Security»
или воспользуйтесь кнопкой **Report a vulnerability** во вкладке Security этого репозитория.

Мы ответим в течение 72 часов.

## Правила для участников

- Пароли, токены, ключи, IP-адреса серверов и данные игроков никогда не коммитятся.
- Секреты хранятся в `secrets.env` / `.env` на сервере или в GitHub Actions Secrets.
- Если секрет всё же попал в git, его считают скомпрометированным: сразу перевыпустить, затем чистить историю.

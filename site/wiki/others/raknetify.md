# Подключение через Raknetify

Если в вашем клиенте установлен мод [Raknetify](https://modrinth.com/plugin/raknetify), подключайтесь к серверу через него: задержка будет ниже.

Используйте один из этих адресов:

| Адрес | Когда использовать |
| --- | --- |
| `raknet;mc.orichill.net` | основной вариант |
| `raknetl;mc.orichill.net` | запасной, если первый работает нестабильно |

Вставьте адрес в список серверов как обычный IP и подключайтесь.

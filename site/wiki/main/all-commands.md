# Команды

Аргументы в угловых скобках, например `<ник>`, нужно заменить своими значениями. Команды для декоративных моделей собраны на [отдельной странице](../mechanics/dekorate-model#команды).

## Аккаунт

| Команда | Что делает |
| --- | --- |
| `/register` или `/reg` | зарегистрироваться |
| `/login` или `/l` | войти в аккаунт |
| `/changepassword` | сменить пароль |
| `/unregister` | удалить аккаунт |

## Телепортация

| Команда | Что делает |
| --- | --- |
| `/tpa <ник>` или `/call` | запросить телепорт к игроку |
| `/tpahere <ник>` | позвать игрока к себе |
| `/tpaccept` | принять запрос |
| `/tpdeny` или `/tpacancel` | отклонить запрос |
| `/tptoggle` | запретить или разрешить запросы к вам |

## Дом

| Команда | Что делает |
| --- | --- |
| `/sethome` | установить точку дома |
| `/home` | телепортироваться домой |
| `/delhome` | удалить точку дома |

## Варпы

| Команда | Что делает |
| --- | --- |
| `/warps` или `/warp` | список варпов |
| `/warp <название>` | телепортироваться на варп |

## Чат

[Подробнее о чатах](../mechanics/chat)

| Команда | Что делает |
| --- | --- |
| `/msg <ник> <текст>` или `/m` | личное сообщение игроку |
| `/msgtoggle` | включить или выключить личные сообщения |
| `/sms` | включить или выключить автосообщения |

## Скины

| Команда | Что делает |
| --- | --- |
| `/skin set <ник>` | поставить скин лицензионного игрока |
| `/skin url <ссылка>` | поставить скин по ссылке |
| `/skin update` | обновить скин |
| `/skin clear` | убрать установленный скин |

## Защита личных вещей

[Подробнее о защите ЛВ](../mechanics/protect-chest)

| Команда | Что делает |
| --- | --- |
| `/lock` или `/chp lock` | режим блокировки |
| `/unlock` или `/chp unlock` | режим разблокировки |
| `/trust` или `/chp trust` | добавить игрока в доверенные |
| `/untrust` или `/chp untrust` | убрать игрока из доверенных |
| `/chp exit` | выйти из всех режимов |
| `/chp menu` | меню защиты |

| `/rank` | меню рангов |
| `/enchlist` | список кастомных зачарований |

## Позы

## <span class="oc-c-primary">**Наш собственный клиент для игры на ORICHILL**</span>


::: info

<span class="oc-c-blue">`→`</span> Для нашего сервера мы реализовали свой персональный клиент для комфортной игры.\
Он добавляет визуальные улучшения, из-за чего вы действительно сможете насладиться ми на нашем уютном сервере. \
\
Также, клиент основан на мод-паке [**Fabulously Optimized**](https://modrinth.com/modpack/fabulously-optimized), который очень хорошо оптимизирует сам клиент, потому вы можете не опасаться того, что ваш пк не сможет потянуть клиент. \
\
Насчёт минимальных требований, указанных на странице клиента в <kbd><span class="oc-c-success">**Modrinth**</span></kbd>, они были сделаны с учётом использования Шейдеров, поэтому вы можете не обращать внимание на них, если конечно вы их не используете.\
\
`💠` Ссылка для скачивания нашего клиента <span class="oc-c-primary">**`ORICHILL Client`**</span> - [**\*КЛИК** ](https://modrinth.com/modpack/orichill-client) (_**👈 жмяк)**_

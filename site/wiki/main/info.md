# Информация

👾 Добро пожаловать в вики сервера **ORICHILL**! Здесь собраны все особенности, правила и полезная информация. Приятного чтения 🤗

## Как подключиться {#connecting}

::: warning Сначала анкета
Чтобы играть на основном сервере, нужно пройти **верификацию по анкете**. Зайдите в наш [Discord](https://discord.orichill.net/) и откройте анкету: администрация пришлёт её вам для заполнения.
:::

| | |
| --- | --- |
| IP-адрес | `mc.orichill.net` |
| Версии | Java Edition **1.21.11 – 26.3** |
| Рекомендуемая версия | **26.3** — основная версия сервера |
| Discord | [discord.orichill.net](https://discord.orichill.net/) |

Играть можно как с лицензией, так и без неё.

## ORICHILL Client

Мы собрали свой клиент для комфортной игры на сервере. Он добавляет визуальные улучшения, чтобы вы могли насладиться нашим уютным миром.

Клиент основан на сборке [Fabulously Optimized](https://modrinth.com/modpack/fabulously-optimized), которая хорошо оптимизирует игру, так что он пойдёт даже на слабом ПК. Минимальные требования на странице Modrinth указаны с расчётом на шейдеры: если вы их не используете, на требования можно не смотреть.

[Скачать ORICHILL Client на Modrinth](https://modrinth.com/modpack/orichill-client)

## Миры {#worldborder}

Во всех мирах используется собственный генератор. Граница каждого мира — **20 000 блоков** от центра (0, 0) в каждую сторону.

| Мир | Граница |
| --- | --- |
| Обычный мир | 20 000 блоков |
| Незер | 20 000 блоков |
| Энд | 20 000 блоков |

## Перезапуски {#restarts}

Игровые серверы автоматически перезапускаются **каждые 12 часов**. Прокси-сервер при этом не перезапускается.

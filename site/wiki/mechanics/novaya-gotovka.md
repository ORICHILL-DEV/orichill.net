# Новая готовка

В кастрюле можно приготовить 27 новых блюд из двух ингредиентов.

::: warning Возможны баги
Мы знаем о багах готовки, но пока не можем их исправить. Сообщать о них не нужно.
:::

## Крафт кастрюли

Подойдёт любой забор.

![Крафт кастрюли](/assets/wiki/%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%2837%29.png)

## Рецепты

::: tip Порядок неважен
Ингредиенты можно класть в любом порядке. Любое сочетание не из списка превратится в **Отвратительное блюдо**.
:::

### Бутерброды и бургеры

| Ингредиенты | Блюдо |
| --- | --- |
| Сырая треска + Хлеб | **Сэндвич с треской** |
| Сырой лосось + Хлеб | **Сэндвич с лососем** |
| Сырая говядина + Хлеб | **Бургер** |
| Сырая курица + Хлеб | **Куриный сэндвич** |
| Сырая свинина + Хлеб | **Сэндвич с ветчиной** |
| Яйцо + Хлеб | **Яйцо в корзинке** |

### Мясо и рыба

| Ингредиенты | Блюдо |
| --- | --- |
| Мёд + Свинина | **Глазированная ветчина** |
| Свинина + Яблоко | **Свиные отбивные с яблочным пюре** |
| Сырая говядина + Палка | **Кебаб из говядины** |
| Сырая курица + Палка | **Куриный кебаб** |
| Молоко + Сырая говядина | **Молочный стейк** |
| Сырая говядина + Яйцо | **Стейк с яйцами** |
| Сырая свинина + Яйцо | **Бекон с яйцами** |
| Сырая треска + Картофель | **Рыба с жареным картофелем** |
| Сырой лосось + Сушёная ламинария | **Суши с лососем** |
| Сырая треска + Сушёная ламинария | **Суши с треской** |

### Сладкое

| Ингредиенты | Блюдо |
| --- | --- |
| Фрукт + Другой фрукт | **Фруктовый салат** |
| Яблоко + Хлеб | **Яблочная слойка** |
| Сахар + Яблоко | **Яблоко в карамели** |
| Какао-бобы + Хлеб | **Брауни** |
| Хлеб + Сахар | **Пончик** |
| Мёд + Хлеб | **Блины** |
| Какао-бобы + Сахар | **Плитка шоколада** |
| Сахар + Палка | **Леденец** |
| Сахар + Нить | **Сладкая вата** |

### Напитки

| Ингредиенты | Блюдо |
| --- | --- |
| Какао-бобы + Молоко | **Шоколадное молоко** |
| Сладкие ягоды + Молоко | **Ягодное молоко** |

Для фруктового салата нужны два **разных** фрукта.

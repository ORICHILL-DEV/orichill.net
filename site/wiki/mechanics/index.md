# Механики

## <span class="oc-c-primary">Механики</span>

<details>

<summary><kbd><span class="oc-c-primary"><strong>ℹ️ СПИСОК МАЛОЗАМЕТНЫХ МЕХАНИК</strong></span></kbd></summary>

* <kbd>**‣**</kbd>**&#x20;Индикаторы** температуры, здоровья, скиллов в панели **ActionBar**.
* <kbd>**‣**</kbd>**&#x20;Беконизация.**
* <kbd>**‣**</kbd>**&#x20;Рандомный Спавн**.
* <kbd>**‣**</kbd> Кастомные крафты.
* <kbd>**‣**</kbd>**&#x20;Анимации смерти игроков**.&#x20;
* <kbd>**‣**</kbd> У мобов теперь имеется свой уровень, что способствует повышению урона и скорости передвижения и в целом - усложняет игровой процесс игрока.
* <kbd>**‣**</kbd>**&#x20;Выносливость.** Появление шкалы в **BossBar при беге, прыжках, плавании.**
* <kbd>**‣**</kbd>**&#x20;Якоря возрождения** отключены.
* <kbd>**‣**</kbd>**&#x20;Ограничение скорости элитр.** \
  <kbd>_**^Причина:**_</kbd> \
  _`"Из-за понижения производительности сервера во время полёта игроков, мы приняли решение ограничить скорость элитр."`_
* <kbd>**‣**</kbd>**&#x20;Координаты отключены во вкладке F3.**\
  <kbd>_**^Пояснение:**_</kbd> Для усложнения игрового процесса. Теперь, чтобы узнать координаты, надо иметь компас.&#x20;
* <kbd>**‣**</kbd>**&#x20;Изменение в игровой процесс:** Резная Книжная Полка обеспечивает свойство для **Стола Зачарования**, как обычная **Книжная Полка**.
* <kbd>**‣**</kbd>**&#x20;Изменение в игровой процесс:** Укрепленный Глубокий Сланец теперь падает при добыче инструментом с шелковистым прикосновением.
* <kbd>**‣**</kbd> Отключение надписи в **Наковальне** и в **Столе Зачарования** "**Очень Дорого**".
* <kbd>**‣**</kbd> Фантомы стали **Дроном-Камикадзе**.&#x20;
* <kbd>**‣**</kbd> Добавлена возможность для **Тотема Бессмертия**, которая теперь может спасти игрока от смерти **в пустоте**, телепортируя в последнее место, где его ноги коснулись земли. Если по какой-либо причине эта позиция не будет найдена, они будут телепортированы на точку возрождения.
* <kbd>**‣**</kbd> Игроки могут возвращать чары предмета в виде книги с помощью наковальни за 25 уровней опыта.
* <kbd>**‣**</kbd> Деревянные рецепты для камнереза.
* <kbd>**‣**</kbd>**&#x20;Авто-Компостер.** (<span class="oc-c-danger">Удалена в обновлении</span> <span class="oc-c-danger"></span><span class="oc-c-danger">**R.26-1\_21\_11-1**</span>)

</details>

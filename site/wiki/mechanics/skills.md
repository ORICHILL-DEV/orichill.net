# Навыки и статы

::: tip Не путайте навыки и статы
- **Навыки** прокачиваются, когда вы что-то делаете в игре, и с каждым уровнем дают бонусы.
- **Статы** — это характеристики персонажа. Они растут благодаря навыкам.
:::

## Навыки

Навык растёт, пока вы занимаетесь определённым делом. За каждый новый уровень вы получаете эффекты, улучшение статов и другие бонусы.

Всего навыков девять:

| Навык | Как получать опыт |
| --- | --- |
| ⛏️ **Шахтёрство** | разбивайте блоки |
| ⚔️ **Бой** | убивайте мобов |
| 🔮 **Зачарование** | зачаровывайте предметы |
| 🌾 **Фермерство** | собирайте урожай |
| 🪓 **Лесорубство** | рубите деревья |
| 🎣 **Рыболовство** | рыбачьте |
| 🧪 **Алхимия** | варите зелья |
| 🩻 **Мазохизм** | получайте урон |
| 🕶️ **Разведка** | передвигайтесь по миру |

Быстрее качать навыки помогают [квесты](./kvesty).

## Статы

Статы — это характеристики вашего персонажа. Сейчас работают семь:

| Стат | Что даёт |
| --- | --- |
| 🛡️ **Защита** | уменьшает получаемый урон |
| 💪 **Сила** | увеличивает наносимый урон |
| 👋 **Шанс крита** | повышает шанс критического удара |
| 🏈 **Критический урон** | увеличивает урон от критического удара |
| 🚀 **Скорость** | ускоряет передвижение |
| 🦉 **Мудрость** | увеличивает получаемый опыт (и максимум маны, если она используется) |
| 🫨 **Свирепость** | даёт шанс ударить дважды |

::: details Отключённые статы
| Стат | Что давал бы |
| --- | --- |
| ❤️ **Здоровье** | увеличивает максимальное здоровье |
| ⛷️ **Скорость атаки** | ускоряет атаку |
:::

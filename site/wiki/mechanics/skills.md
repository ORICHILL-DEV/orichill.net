# Навыки&#x20;

***


::: warning

<kbd><span class="oc-c-orange">**⚠️ ПРИМЕЧАНИЕ ⚠️**</span></kbd> \
<kbd><span class="oc-c-warning">↳</span></kbd> **Не путайте Навыки и Статы, это два разных понятия!**\
\
\- <kbd><span class="oc-c-red">**Статы**</span></kbd> - Это характеристики вашего персонажа, которые прокачиваются с помощью **навыков**.\
\- <kbd><span class="oc-c-blue">**Навыки/Скиллы**</span></kbd> - Дают эффекты, характеристики и другие бонусы.
:::

***

## <span class="oc-c-primary">Навыки</span>

Навыки повышаются путем выполнения определенных задач и дают эффекты, характеристики и другие бонусы, при повышении уровня.\
\
<kbd>**Всего навыков 9, а именно:**</kbd>

| Навык                                                                                       | Задача                                        |
| ------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `⛏️` <kbd><span class="oc-c-primary">**Шахтёрство**</span></kbd>  | _Разбивайте блоки, чтобы заработать XP_       |
| `⚔️` <kbd><span class="oc-c-info">**Боевой**</span></kbd>            | _Убивайте мобов, чтобы заработать XP_         |
| `🔮` <kbd><span class="oc-c-success">**Зачарование**</span></kbd> | _Зачаровывайте предметы, чтобы заработать XP_ |
| `🌾` <kbd><span class="oc-c-warning">**Фермерство**</span></kbd>  | _Собирайте урожай, чтобы заработать XP._      |
| `🪓` <kbd><span class="oc-c-danger">**Лесорубство**</span></kbd>   | _Рубите деревья, чтобы заработать XP_         |
| `🎣` <kbd><span class="oc-c-blue">**Рыболовство**</span></kbd>         | _Рыбачьте, чтобы заработать XP_               |
| `🧪` <kbd><span class="oc-c-purple">**Алхимия**</span></kbd>         | _Варите зелья, чтобы заработать XP_           |
| `🩻` <kbd><span class="oc-c-orange">**Мазохизм**</span></kbd>        | _Получайте урон, чтобы заработать XP_         |
| `🕶️` <kbd><span class="oc-c-green">**Разведка**</span></kbd>         | _Двигайтесь, чтобы заработать XP_             |

***

## <span class="oc-c-primary">Статы</span>

<kbd><span class="oc-c-primary">**Описание:**</span></kbd> _Это характеристики вашего персонажа._\
\
<kbd>**Всего статов 7, а именно:**</kbd>

| Статы                                                                                                                                                                              | Описание                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `🛡️` <kbd><span class="oc-c-yellow">**Защита**</span></kbd>                                                                                                | _Уменьшает входящий урон_                                                        |
| `💪` <kbd><span class="oc-c-red">**Сила**</span></kbd>                                                                                                         | _Увеличивает исходящий урон_                                                     |
| `👋` <kbd><span class="oc-c-orange">**Шанс Критического Удара**</span></kbd>                                                                                | _Увеличивает шанс нанести критический удар._                                     |
| `🏈` <kbd><span class="oc-c-danger">**Критический Урон**</span></kbd>                                                                                     | _Увеличивает критический урон_                                                   |
| `🚀` <kbd><span class="oc-c-success">**Скорость**</span></kbd>                                                                                           | _Увеличивает скорость передвижения_                                              |
| `🦉` <kbd><span class="oc-c-primary">**Мудрость**</span></kbd>                                                                                           | _Увеличивает получаемый опыт (и максимальное количество маны при использовании)_ |
| `❤️` <kbd><span class="oc-c-danger">**Здоровье**</span></kbd> <span class="oc-c-red">**(\*отключено\*)**</span>                                         | _Увеличивает максимальное здоровье_                                              |
| `🫨` <kbd><span class="oc-c-purple">**Свирепость**</span></kbd>                                                                                             | _Шанс попасть дважды_                                                            |
| `⛷️` <kbd><span class="oc-c-warning">**Скорость атаки**</span></kbd> <span class="oc-c-red">(\*</span><span class="oc-c-red">**отключено\*)**</span> | _Увеличивает вашу скорость атаки_                                                |

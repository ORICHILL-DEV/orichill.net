# Декоративные Модели

[▶ Видео](https://youtu.be/jaNsdR6UBNI)

## <span class="oc-c-primary">Использование</span>

Для использования, вам, как минимум, нужна **`Стока для Брони`**, после чего вводим команду \
<kbd><span class="oc-c-primary">**/eas give**</span></kbd>, чтобы получить **`Редактор (EAS)`**&#x438; начинаем редактировать Модель.

## <span class="oc-c-primary">Команды</span>

<span class="oc-c-primary">**`/eas align`**</span> - переместить выбранную сущность в центр блока\
<span class="oc-c-primary">**`/eas cantick`**</span> - вкл./выкл. тикание выбранной подставки для брони\
<span class="oc-c-primary">**`/eas clipboard`**</span> - показать буфер обмена\
<span class="oc-c-primary">**`/eas copy`**</span> - скопировать все свойства выбранной сущности\
<span class="oc-c-primary">**`/eas give`**</span> - выдать инструмент <span class="oc-c-primary">`Редактор (EAS)`</span>\
<span class="oc-c-primary">**`/eas help`**</span> - показать справку по командам\
<span class="oc-c-primary">**`/eas history`**</span> - посмотреть историю\
<span class="oc-c-primary">**`/eas info`**</span> - просмотреть подробную информацию о выбранной сущности\
<span class="oc-c-primary">**`/eas open`**</span> - открыть меню\
<span class="oc-c-primary">**`/eas paste`**</span> - применить буфер обмена к выбранной сущности\
<span class="oc-c-primary">**`/eas pitch`**</span> - установить угол наклона выбранной сущности\
<span class="oc-c-primary">**`/eas position`**</span> - телепортировать выбранную сущность\
<span class="oc-c-primary">**`/eas reset`**</span> - сбросить значение выбранного инструмента\
<span class="oc-c-primary">**`/eas select`**</span> - выбрать соответствующие сущности с помощью селектора\
<span class="oc-c-primary">**`/eas set`**</span> - установить значение выбранного инструмента\
<span class="oc-c-primary">**`/eas snap angle`**</span> - изменить шаг привязки угла\
<span class="oc-c-primary">**`/eas snap move`**</span> - изменить шаг привязки позиции\
<span class="oc-c-primary">**`/eas yap`**</span> - изменить направление взгляда выбранной сущности

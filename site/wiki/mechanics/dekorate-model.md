# Декоративные модели

Из стойки для брони можно сделать декоративную модель: повернуть, наклонить и расставить её как угодно.

[▶ Смотреть видеообзор на YouTube](https://youtu.be/jaNsdR6UBNI)

## Как начать

1. Поставьте стойку для брони.
2. Введите `/eas give`, чтобы получить инструмент **Редактор (EAS)**.
3. Выберите стойку редактором и настраивайте модель.

## Команды

### Основные

| Команда | Что делает |
| --- | --- |
| `/eas give` | выдаёт инструмент «Редактор (EAS)» |
| `/eas open` | открывает меню |
| `/eas help` | показывает справку по командам |
| `/eas info` | подробная информация о выбранной сущности |
| `/eas history` | история изменений |

### Выбор и копирование

| Команда | Что делает |
| --- | --- |
| `/eas select` | выбирает сущности с помощью селектора |
| `/eas copy` | копирует все свойства выбранной сущности |
| `/eas clipboard` | показывает буфер обмена |
| `/eas paste` | применяет буфер обмена к выбранной сущности |

### Положение и поворот

| Команда | Что делает |
| --- | --- |
| `/eas align` | ставит выбранную сущность в центр блока |
| `/eas position` | телепортирует выбранную сущность |
| `/eas pitch` | задаёт угол наклона |
| `/eas yap` | меняет направление взгляда |
| `/eas snap angle` | меняет шаг привязки угла |
| `/eas snap move` | меняет шаг привязки позиции |

### Инструменты

| Команда | Что делает |
| --- | --- |
| `/eas set` | задаёт значение выбранного инструмента |
| `/eas reset` | сбрасывает значение выбранного инструмента |
| `/eas cantick` | включает или выключает тикание выбранной стойки |

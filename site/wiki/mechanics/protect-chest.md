# Защита ЛВ

**ЛВ** — личные вещи. Сундуки, двери, печи и даже животных можно закрыть от посторонних игроков.

## Команды

| Команда | Что делает |
| --- | --- |
| `/lock` или `/chp lock` | включает режим блокировки |
| `/unlock` или `/chp unlock` | включает режим разблокировки |
| `/trust` или `/chp trust` | добавляет игрока в доверенные |
| `/untrust` или `/chp untrust` | убирает игрока из доверенных |
| `/chp exit` | выходит из всех режимов выше |
| `/chp menu` | открывает меню защиты |

## Что можно защитить

::: details Блоки
Сундук, бочка, печи, коптильня, узорная ваза, маяк, вагонетки, полки, улей, калитки, двери, люки, кафедра, рамка, шалкер, кровать, воронка, нажимная плита, резная книжная полка, картины, выбрасыватель, раздатчик, стойка для брони, рычаг, датчик дневного света, сборщик.
:::

::: details Существа
Корова, овца, свинья, курица, дельфин, осёл, лошадь, лиса, лама, грибная корова, оцелот, панда, попугай, волк, черепаха.
:::

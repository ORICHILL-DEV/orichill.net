# Чаты

На сервере три вида сообщений.

## Глобальный чат

Просто напишите сообщение в чат. Его увидят **все игроки** на сервере.

![Глобальный чат](/assets/wiki/%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%2850%29.png)

![Сообщение в глобальном чате](/assets/wiki/%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%2856%29.png)

## Локальный чат

Поставьте `*` перед сообщением, например `*привет`. Его увидят игроки в радиусе **38 блоков**, а над вашей головой появится облачко с текстом.

![Сообщение из локального чата](/assets/wiki/%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%2855%29.png)

## Личные сообщения

```
/msg <ник> <сообщение>
/m <ник> <сообщение>
```

Сообщение увидит только указанный игрок.

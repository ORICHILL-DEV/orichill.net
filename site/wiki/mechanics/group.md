# Привилегии

## Команда проекта

| Роль | Кто это |
| --- | --- |
| <span class="oc-c-danger">**OWNER**</span> | руководитель и главный разработчик проекта |
| <span class="oc-c-warning">**TECHNICAL ADMINISTRATOR**</span> | технический администратор |
| <span class="oc-c-primary">**ADMINISTRATOR**</span> | администратор всего проекта |
| <span class="oc-c-info">**CURATOR**</span> | куратор проекта |
| <span class="oc-c-tint">**KGB**</span> | модератор сервера |

## Привилегии игроков

| Привилегия | Как получить |
| --- | --- |
| <span class="oc-c-orange">**VETERAN**</span> | выдаётся автоматически за получение ранга **S** ([подробнее о рангах](./ranks)) |
| <span class="oc-c-blue">**SPONSOR**</span> | для тех, кто поддержал сервер. Даёт те же возможности, что и VETERAN |

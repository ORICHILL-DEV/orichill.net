# Кастомные зачарования

::: tip Точный список в игре
Названия здесь взяты из документации плагина и могут отличаться от игровых. Актуальный список всегда можно посмотреть командой `/enchlist`.
:::

## Инструменты

| Чары | Что делает |
| --- | --- |
| **Раскопки** | добывает сразу область 1×2, крест, 3×3 или больше. Эффект отключается, если зажать <kbd>Shift</kbd> |
| **Вырубка лесов** | срубает всё дерево целиком за один блок |
| **Телекинез** | добыча из разбитых блоков сразу попадает в инвентарь |
| **Родство** | восстанавливает часть прочности, если добывать руду киркой из того же материала (например, алмазную руду алмазной киркой) |
| **Закалённый солнцем** | сразу переплавляет добычу из блоков |
| **Подсветка** | <kbd>ПКМ</kbd> инструментом ставит факел за счёт прочности |
| **Сбор урожая** | <kbd>ПКМ</kbd> по созревшему урожаю мгновенно собирает и пересаживает его |
| **Ударная волна** | <kbd>ПКМ</kbd> по верхней грани блока отбрасывает всех мобов вокруг. Есть перезарядка, эффект слабее против защиты от отбрасывания |

## Луки и арбалеты

| Чары | Что делает |
| --- | --- |
| **Шквал атак** | даёт шанс выпустить несколько стрел подряд. Каждая слабее обычной, но снимает с цели неуязвимость после удара, поэтому все попадания вместе наносят куда больше урона. Каждая стрела может срабатывать вместе с другими чарами |
| **Суперклей** | при попадании может «привязать» врага невидимой верёвкой и через мгновение притянуть к вам |
| **Рассеянный выстрел** | попадание наносит часть урона всем вокруг цели <Badge type="danger" text="может отсутствовать" /> |

## Оружие

| Чары | Что делает |
| --- | --- |
| **Варвар** | увеличивает урон от атаки |
| **Вампиризм** | восстанавливает здоровье, когда вы кого-то убиваете |
| **Ослабление** | с убитых существ выпадает больше опыта |
| **Палач** | криперы, скелеты, игроки и другие мобы могут уронить свою голову |
| **Токсичность** | удар снижает лечение цели на 40/60/80% на время |
| **Сокрушение** | увеличивает урон по целям в тяжёлой броне (железо, золото, алмаз) за каждую её часть |
| **Перфорация** | то же, что Сокрушение, но против лёгкой брони (кожа, кольчуга, алмаз — алмаз легче железа и золота) |
| **Свеча покойника** | убитые существа взрываются, нанося урон и поджигая всех вокруг <Badge type="danger" text="может отсутствовать" /> |

## Броня и щиты

| Чары | Что делает |
| --- | --- |
| **Метаболизм** | усиливает лечение на 5% за уровень. Бонусы со всех частей брони складываются, максимум 100% |
| **Энергичный** | увеличивает максимальное здоровье |
| **Покрытие** | добавляет очки брони |
| **Экранирование** | даёт шанс отразить летящий в вас снаряд |
| **Устойчивость** | повышает сопротивление отбрасыванию |
| **Внутривенное питание** | медленно восстанавливает голод |
| **Крылья** | позволяют недолго летать за счёт прочности. Полёт перезаряжается, пока вы стоите на земле |
| **Лавовый ходок** | как «Ледоход», но для лавы: превращает лаву рядом во временную магму за счёт прочности |
| **Базальтовая кожа** | даёт огнестойкость, пока предмет надет или в руке, но замедляет, пока вы горите |
| **Мимолётность** | увеличивает скорость передвижения |
| **Сотрясатель земли** | защищает от урона при падении. Падение с большой высоты вызывает взрыв: чем выше, тем сильнее. В 1.20.5+ присед ускоряет падение |
| **Нейтрализатор** | для щита: если заблокировать взрывное или оседающее зелье, оно на вас не подействует |
| **Эффективность** | выпитые зелья сильнее, но короче. Например, Сила II на 1:30 становится Силой IV на 0:45 <Badge type="danger" text="может отсутствовать" /> |

## Любые предметы

| Чары | Что делает |
| --- | --- |
| **Привязь к душе** | предмет не выпадает при смерти и возвращается в инвентарь после возрождения |
| **Омоложение** | медленно восстанавливает прочность |

## Проклятия

| Чары | Что делает |
| --- | --- |
| **Хрупкость** | противоположность «Прочности»: предмет изнашивается быстрее |
| **Паразит** | вы медленно голодаете |
| **Бремя** | замедляет все ваши движения |

## Пакты

Пакты дают сильный бонус, но с ценой.

| Чары | Что делает |
| --- | --- |
| **Пакт берсерка** | вы наносите больше урона, но и получаете больше |
| **Пакт перфекциониста** | обычный урон ниже, но каждый следующий удар сильнее, пока вас самих не ударят |
| **Пакт феи** | вы становитесь меньше, но уменьшается дальность взаимодействия с блоками и атаки |
| **Пакт Йотуна** | дальность взаимодействия и атаки растёт, но вы становитесь больше |

## Чары с эффектами зелий

### Пока предмет надет или в руке

| Чары | Эффект |
| --- | --- |
| **Благословение** | удача |
| **Жабры** | подводное дыхание |
| **Ночное зрение** | ночное зрение |
| **Прыжок** | прыгучесть |
| **Ускоренный** | спешка |

### При ударе по цели

| Чары | Эффект |
| --- | --- |
| **Ослепляющая мощь** | ослепляет врага |
| **Сотрясение мозга** | может вызвать тошноту |
| **Отравление** | может отравить |
| **Калечение** | может замедлить |
| **Ослабление силы** | ослабляет врага |
| **Иссушающая мощь** | накладывает иссушение |
| **Тупой** | может оглушить. Оглушение не даёт двигаться и атаковать, поэтому срабатывает реже и длится меньше других эффектов |

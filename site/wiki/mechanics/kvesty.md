# Квесты

::: info
После каждого прохождения квеста, он будет доступен через <kbd>_<span class="oc-c-primary">**24 часа**</span>_</kbd>.
:::

## <span class="oc-c-primary">Информация про квесты</span>

На нашем любимом сервере присутствуют квесты. \
Они помогут улучшить геймплей для игроков, которые не могут придумать себе цель, да и с помощью квестов, можно быстрее прокачиваться по навыкам.\
\
**На данный момент всего 5 категорий квестов, а именно:**

* <kbd><span class="oc-c-green">**⛏️**</span></kbd> <span class="oc-c-info">**Добыча руд**</span>
* <kbd><span class="oc-c-purple">**🧙‍♂️**</span></kbd> <span class="oc-c-primary">**Чарующий квест**</span>
* <kbd><span class="oc-c-blue">**🔬**</span></kbd> <span class="oc-c-orange">**Исследование**</span>
* <kbd><span class="oc-c-yellow">**🧑‍🌾**</span></kbd> <span class="oc-c-success">**Фермерство**</span>
* <kbd><span class="oc-c-orange">**🎣**</span></kbd> <span class="oc-c-blue">**Рыболовство**</span>


::: info

Для просмотра квестов, используйте команду: <kbd><span class="oc-c-primary">**/quest**</span></kbd>, либо через меню сервера: <kbd><span class="oc-c-primary">**/menu**</span></kbd>
:::

# Квесты

Квесты помогают, когда не знаете, чем заняться, и ускоряют прокачку [навыков](./skills).

## Категории

Сейчас на сервере пять категорий квестов:

| | Категория |
| --- | --- |
| ⛏️ | Добыча руд |
| 🧙‍♂️ | Чарующий квест |
| 🔬 | Исследование |
| 🧑‍🌾 | Фермерство |
| 🎣 | Рыболовство |

## Как открыть

Введите `/quest` или откройте меню сервера командой `/menu`.

::: info Перезарядка
Пройденный квест снова станет доступен через **24 часа**.
:::
